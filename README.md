# 🔢 MNIST AI Studio — Autoencoder + CNN Classification

A two-model TensorFlow/Keras project that **reconstructs** MNIST handwritten digits with an autoencoder and **classifies** them with a separately trained CNN. The Streamlit interface uses a dark navy and purple theme.

## What each model does

- **Autoencoder:** compresses 28×28 grayscale MNIST digits through a 32-number bottleneck and reconstructs the original images. Trained for 3 epochs using reconstruction loss.
- **CNN classifier:** learns supervised labels 0–9 from the MNIST training set and predicts 10 digit probabilities. Train separately; final test accuracy and a confusion matrix are saved automatically.

The autoencoder **does not classify** digits. The classification feature requires its own model weights.

## Train models with VS Code (no virtual environment)

From the project folder:

```bash
python -m pip install -r requirements.txt
```

**Existing autoencoder:** If the autoencoder file is missing, run:

```bash
python train_autoencoder.py
```

This saves `outputs/mnist_autoencoder.keras`. Keep the previous trained file if you already have it.

**New classifier:**

```bash
python train_classifier.py --epochs 5
```

This saves `outputs/mnist_classifier.keras`, a confusion matrix, an accuracy chart, and `classifier_metrics.json` with measured test results. Actual accuracy is determined by running this training and evaluation; it is not guaranteed in advance.

## Local Streamlit run

```bash
python -m streamlit run app.py
```

## Upload to existing GitHub repository

Go to https://github.com/charlyclassy/MNIST-Autoencoder-GitHub-Streamlit-Project and **replace** `app.py`, `README.md`, `requirements.txt`, and `train_autoencoder.py` with files from the ZIP. **Add** `train_classifier.py` and `.streamlit/config.toml`. Put the real trained `.keras` files and results inside `outputs/`.

If GitHub's website file uploader places everything in the root, create folders using **Add file → Create new file** with path `.streamlit/config.toml`, and visit `outputs/` before uploading model files.

## Deploy on Streamlit Cloud

Use existing repository, branch `main`, and main file `app.py`. After pushing changes, let Streamlit redeploy. Classifier view displays a helpful warning until the new model is uploaded. Reconstruct view likewise needs the saved autoencoder.

## Note on uploaded handwriting

The app supports a **single digit per upload**. To match MNIST, use white strokes on a black background (or select inversion), optionally crop and centre the digit. The CNN's test accuracy on MNIST may not transfer to photographs or non-MNIST handwriting.

## Assignment concepts

- **Encoder:** makes a shorter representation of an image.
- **Bottleneck:** a 32-value compressed representation.
- **Decoder:** rebuilds the image.
- **Reconstruction loss:** measures the difference between original and reconstructed pixels.
- **Classifier:** predicts the label 0–9, instead of reconstructing pixels.
